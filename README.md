# 交前看一眼

提交材料前，检查一下。面向参赛、报名与作业提交的中文本地网页工具。

## 启动与构建

需要 Node.js 22 或更新版本（本轮使用 Node.js 24）。

```sh
npm ci --cache /tmp/examer-npm-cache
npm run dev
```

打开终端显示的开发地址。生产构建：`npm run build`，静态产物位于 `dist/`，可部署到普通静态托管服务。测试：`npm test`。无登录、数据库、后端或 API 密钥。

## 使用

1. 确认要求：使用空白清单或“智核杯—AI 实用作品赛道”示例，编辑必交、扩展名、最少数量、体积和关键词。队名、作品名和 ZIP 模板可编辑。要求自动存入 localStorage，也能导入导出 JSON。
2. 拖入或多选文件，为每个文件手动指定材料。一项材料允许多份文件；删除材料后，对应文件回到未归类状态。不会自动认定材料满足要求。
3. 查看真实问题，修正清单、文件归类和导出名称。批量添加队名或作品名前缀只影响 ZIP，不修改原文件。格式不对时应替换文件；重命名扩展名不能转换文件内容。
4. 勾选实际核对的人工确认项，预览 ZIP 根目录并导出。所有结构问题修正后才能导出；未完成人工确认时仍可导出，但报告明确保留待确认事项。

“体验示例”生成无隐私文本文件，故意保留视频、Prompt 日志缺失，说明扩展名错误和文件名冲突。没有伪造视频。可一键清空示例文件。切换清单会保留文件但取消归类。

## 检查规则与边界

- 扩展名与文件名关键词忽略大小写。MB 为 1024×1024 字节，等于上限可以通过。
- 必交至少一份；可选项未提交不要求最低数量，提交后才检查最少数量。
- 视频通过浏览器 metadata 读取实际时长；超过 180 秒报问题，无法读取或超过 6 秒未读取成功时需要人工确认。浏览器与编码兼容性可能不同。
- 所有 ZIP 文件都在根目录。拒绝路径分隔符、路径穿越、控制字符、Windows 保留名、结尾点/空格和超过 240 UTF-8 字节的名称。不会自动静默清洗名称；用户修改后再检查。
- 重名按 Unicode NFC 和忽略大小写比较，报告文件名 `检查报告.md` 也属于保留路径，不会静默覆盖。
- JSON 导入有结构、数字范围、唯一材料 ID 校验与 1 MB 限制。
- 仅检查文件结构、用户规则和可读取的视频时长。扩展名不验证真实文件格式；不会审阅说明页数、Prompt 日志内容、作品原创性或链接可访问性。“已通过”不代表主办方审核通过。示例以官方通知为准，不编造大小限制。
- 文件只在浏览器内存中处理，不上传。刷新后要求保留，但文件必须重新选择；文件和规则变更后人工确认会重置。共享浏览器的 localStorage 可能被同一设备其他使用者读取，清单中不应填写敏感内容。
- fflate 在内存中压缩，超大文件可能导致浏览器卡顿或内存不足，错误会提示。未做大文件压力或所有手机浏览器兼容性测试。

## 验证

`npm test` 包含 10 项核心测试，覆盖缺失、大小写、大小边界、数量、归类变化、冲突、非法名、视频阈值、JSON 和 ZIP 内容一致性。`npm run build` 执行 TypeScript 检查及生产构建。

本轮另使用实际 Chromium 验证示例错误、错误阻止导出、编辑要求、选择及归类文件、确认、真实下载、刷新保存和 390px 手机布局，结果见开发记录。测试下载和截图保存在忽略的 `artifacts/`，不属于应用功能。
